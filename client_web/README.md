# Client Web Interface

`index.html` and `css/` implement the static shell for Task 6 (Client Web
Interface — a public page that asks natural-language questions about
products and stock). `js/api.js`, `js/app.js` and `js/ui.js` are
intentionally empty.

**Task 5 (AI Query Service) and Task 6 (Client Web Interface) are out of
scope for this project** — decided with the project supervisor. There is no
AI Query Service to connect this page to, so it isn't wired up. This is a
scope decision, not unfinished work — see `docs/plan-backend-securite.md`
for context.
